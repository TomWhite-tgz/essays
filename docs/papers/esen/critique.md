# 分子结果, 效率与审读结论

## SPICE-MACE-OFF 静态测试

eSEN 同时在无机材料和有机分子上测试. SPICE-MACE-OFF 由 SPICE 扩展而来, 表中 energy 单位为 meV/atom, force 单位为 meV/Å.

| Split | MACE-4.7M E/F | EscAIP-45M E/F | eSEN-3.2M E/F | eSEN-6.5M E/F |
| --- | ---: | ---: | ---: | ---: |
| PubChem | 0.88 / 14.75 | 0.53 / 5.86 | 0.22 / 6.10 | **0.15 / 4.21** |
| DES370K monomers | 0.59 / 6.58 | 0.41 / 3.48 | 0.17 / 1.85 | **0.13 / 1.24** |
| DES370K dimers | 0.54 / 6.62 | 0.38 / 2.18 | 0.20 / 2.77 | **0.15 / 2.12** |
| Dipeptides | 0.42 / 10.19 | 0.31 / 5.21 | 0.10 / 3.04 | **0.07 / 2.00** |
| Solvated amino acids | 0.98 / 19.43 | 0.61 / 11.52 | 0.30 / 5.76 | **0.25 / 3.68** |
| Water | 0.83 / 13.57 | 0.72 / 10.31 | 0.24 / 3.88 | **0.15 / 2.50** |
| QMugs | 0.45 / 16.93 | 0.41 / 8.74 | 0.16 / 5.70 | **0.12 / 3.78** |

论文报告 eSEN-6.5M 在全部 7 个 split 的 energy 与 force MAE 都优于两项基线. 这里的对比支持有机静态精度, 而 MD22 的 100 ps 守恒消融负责支持 OOD 动力学平滑性.

## 推理效率

作者在单张 80GB NVIDIA A100 上, 使用 Python 3.12, PyTorch 2.4.0 和 CUDA 12.1, 不使用 compile 或 TorchScript, 与 MACE-OFF-L 的公开 benchmark 环境对齐.

![推理效率](/images/esen/inference.png)

216 个碳原子时, eSEN-3.2M, eSEN-6.4M 与 MACE-OFF-L 分别约可运行 0.4, 0.8 和 0.7 million steps/day. 参数更少不自动更快, 因为球谐阶数, 邻居数, kernel 实现和自动微分路径都影响实际吞吐.

## 论文最强的贡献

最重要的贡献不是又刷新一个 leaderboard, 而是把三个原本分散的问题连成可操作链条:

1. 静态误差与物性性能可能脱钩.
2. OOD NVE 能量守恒测试能暴露非保守或粗糙 PES.
3. 失败可追溯到具体架构选择, 包括 grid aliasing, top-$K$ 邻居跳变, 硬截断和过高径向频率.

这使 "光滑" 从模糊审美变成可以通过轨迹压力测试和逐项消融检查的工程要求.

## 证据边界

### 相关性不是充分性

通过守恒测试的模型整体表现更稳健, 但论文也明确指出, 未通过的模型仍可能在某些单项物性上表现良好. 因此守恒测试适合做 rejection gate, 不适合作为唯一排名指标.

### 测试协议不是普适定理

TM23 和 MD22 覆盖了缺陷金属与大有机分子, 但未覆盖液体, 反应, 带电体系, 表面, 极端压强或长达纳秒以上的轨迹. 5 fs 对过渡金属与 1 fs 对有机分子的结论不能自动迁移到所有体系.

### 数据与架构仍有混杂

compliant Matbench 较好地控制 MPTrj 数据来源, 但不同模型可能仍用不同子集, 训练日程和 loss. non-compliant 结果更明显混合 OMat24, sAlex 与 MPTrj 的数据优势. eSEN-OAM 的提升不能全部归因于 smooth architecture.

### 平滑与精确是两个轴

一个很光滑但系统性偏离 DFT 的 PES 可以稳定守恒错误能量. 一个局部很准但粗糙的 PES 可以在静态测试获胜而动力学失败. 完整评估必须同时保留 test accuracy 与 conservation test, 再用具体下游任务确认.

## 最终判断

eSEN 给出了一条可信的模型开发原则: 先要求力来自能量, 再消除构图和表征中的不连续或高频伪影, 通过固定协议的 OOD NVE 测试后, 才把静态 energy MAE 用作物性开发的快速代理.

它没有证明一个通用的 "守恒即可靠" 定律. 它更准确地建立了一个层级式评测框架:

$$
\text{静态拟合精度}
\longrightarrow
\text{实际能量守恒门槛}
\longrightarrow
\text{性质专用验证}.
$$

这个框架比单独的 SOTA 数字更值得沿用.
