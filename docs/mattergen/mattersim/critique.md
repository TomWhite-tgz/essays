# 6. 局限与审读结论

## 作者明确承认的局限

论文 Discussion 已经列出若干重要边界:

::: details 英文原文: 训练范围的关键限制
> "As for data coverage, the current model is trained only on homogeneous bulk systems, without explicit inclusion of surface and interface data that are crucial for applications such as catalysis. Additionally, the model currently only naively supports inferences with DFT-PBE level of theory, limiting its use for systems involving complex interactions, such as polymers and organic liquids."

第一句限制的是训练构型的形态. MatterSim 的大规模数据主要覆盖均匀 bulk systems, 没有显式系统加入表面和界面数据. 因此, 论文展示的表面和界面零样本 MD 首先证明的是模型可以在这些体系上运行, 不能直接证明其定量精度与 bulk benchmark 相同.

第二句限制的是标注理论和相互作用类型. 原生模型主要学习 DFT-PBE 级标签. 对聚合物和有机液体这类复杂体系, 长程作用和 PBE 本身的近似都可能成为误差来源. 因此, 目标任务如果依赖吸附能, 表面重构, 界面电荷转移或长程分子间作用, 就需要加入目标体系的高质量数据做验证或微调.

原文定位: 主文 Discussion, 最后一段.
:::

1. 模型主要使用半局域原子相互作用描述, 长程作用依靠消息传递或 attention 间接传播.
2. 训练数据主要来自 homogeneous bulk systems, 没有显式系统覆盖表面和界面.
3. 原生理论层级主要是 PBE 或 PBE+U.
4. 原生输出只有能量, 力和应力, 没有电荷, 自旋, 磁矩和电子结构等模态.
5. 聚合物, 有机液体和异质体系中由长程作用主导的性质可能不可靠.

官方代码仓库后来的 model card 也提醒, MatterSim-v1 面向 bulk materials. 表面, 界面和长程作用相关性质最多可能提供定性结果, 定量使用前应微调.

## 局域模型的根本盲区

如果截断半径外的环境只通过有限层消息传递影响中心原子, 模型很难直接表示以下现象:

- 长程静电和介电屏蔽.
- 色散作用.
- 大尺度电荷重排.
- 某些磁有序和电子非局域效应.
- 界面两侧跨较长尺度耦合.

增加数据能改善训练分布内的有效近似, 但不能保证结构表达能力足以分离所有长程物理. 数据覆盖和归纳偏置必须同时考虑.

## 标签理论的上限

MatterSim 可以比直接 DFT 快很多, 但它默认近似的是训练标签而不是自然本身. PBE 在带隙, 色散, 强关联和液态水结构等问题上有系统误差. 如果任务需要更高理论层级, 应当:

1. 明确目标 reference method.
2. 采集目标体系的少量高层级标签.
3. 微调并保留独立验证轨迹.
4. 验证目标可观测量, 不只验证能量和力 MAE.

液态水实验正是一个良好示范. 零样本结果暴露 PBE 偏差, rev-PBE0-D3 微调再把参考理论改变.

## "零样本" 的边界

论文中的 zero-shot 表示没有针对下游体系新增训练数据. 它不表示:

- 训练集中从未出现目标元素.
- 训练集中从未出现相似化学键或配位环境.
- 模型对目标体系具有严格分布外保证.
- 模型无需不确定性监控.

对于高风险模拟, 正确工作流应是先运行 ensemble uncertainty, 对高不确定性帧做 DFT spot checks, 必要时主动学习.

## Benchmark 公平性

论文的有限温压 benchmark 使用与 MatterSim 训练标签相同或接近的 DFT 设置. 这是合理的, 因为它测量各模型对这套势能面的近似能力. 但不同对照模型可能在不同 DFT 数据和能量修正体系上训练.

例如 CHGNet 评测应用 Materials Project 2020 compatibility corrections, 其他模型不使用相同修正. MACE-MP-0 在 MPF-TP 上出现极端大误差, 可能同时反映分布外崩溃, 元素组合问题和不同数据参考的能量偏移. 因而表格适合证明 MatterSim 对目标 PBE 设置更鲁棒, 不适合把所有差距解释成纯网络能力差距.

## 材料发现结论的边界

随机结构搜索中的 1974 个 "新" 稳定结构至少还缺少以下验证:

- 更高精度 DFT 或不同泛函复核.
- 振动稳定性和有限温自由能.
- 对所有竞争相更完整的凸包参照.
- 与数据库结构的严格原型去重.
- 动力学可达性和合成路径.
- 实验合成与表征.

作者已经注意到 Materials Project 阴离子修正对假想材料可能不可靠, 并在元素分布分析中排除含 H, Si, N, Sb, O, S, Se, Te, F, Cl, Br 和 I 的候选. 这说明凸包结果依赖能量校正约定, 不是一个完全无条件的稳定性事实.

## MD 完成不等于 MD 正确

在 118 个体系上达到超过 90% 的运行完成率, 可以说明势在数值上较少产生灾难性发散. 但即使一个过度平滑的错误势也可能稳定运行. 更强的验证应包括:

- 沿整条轨迹抽样 DFT 能量和力.
- RDF, ADF, 扩散系数和热容等统计量.
- 相变温度和状态方程.
- NVE 能量漂移.
- 不同初始条件和时间步的重复实验.

论文在液态水上完成了其中一部分, 对其余 118 个体系则主要验证鲁棒性.

## 复现时必须记录什么

MatterSim 不是一个不会变化的单一对象. 官方仓库提供过不同尺寸和版本的 checkpoint. 复现实验至少应记录:

- 模型版本和 checkpoint 名称.
- M3GNet 或 Graphormer backbone.
- 代码 commit.
- 精度类型和硬件.
- cutoff, neighbor list 和周期边界设置.
- MD 系综, thermostat 或 barostat, 时间步和总时长.
- 结构松弛器, 收敛阈值和最大步数.
- 是否微调, 微调数据的理论层级和划分.

仅写 "使用 MatterSim" 不足以保证复现.

## 证据强度分级

| 结论 | 证据强度 | 理由 |
| --- | --- | --- |
| 有限温压数据显著改善远离平衡态预测 | 强 | 3 类专门 benchmark 上能量, 力和应力一致改善 |
| 势能面足以支持多种 bulk 物理量 | 强 | 声子, 模量, 自由能和相边界提供交叉验证 |
| 预训练可显著减少目标体系数据 | 较强 | 3 个主动学习体系与液态水微调均支持 |
| 零样本适用于所有材料形态 | 弱 | 训练以 bulk 为主, 表面和界面缺少系统定量验证 |
| RSS 已发现 1974 种可合成新材料 | 不成立 | 论文只证明计算候选稳定性, 没有合成证据 |
| 轨迹完成率证明 MD 物理正确 | 不成立 | 完成率主要是数值鲁棒性指标 |

## 最终评价

<div class="verdict">
MatterSim 的核心贡献是把通用原子势从 "接近平衡态数据库上的准确回归器" 推进为 "能够在广泛 bulk 构型空间中承担模拟任务的预训练势". 论文的最大价值来自数据生成闭环和跨物理量验证, 不是某个孤立排行榜数字. 它仍不是无需验证的材料模拟万能替代品. 对表面, 界面, 长程作用, 更高理论层级和真正分布外体系, 不确定性检查, DFT 复核与微调仍然必要.
</div>

## 读完后应记住的 5 件事

1. 通用 MLIP 的关键瓶颈之一是构型覆盖, 不只是元素覆盖.
2. 温度和压力通过改变采样构型影响模型, 不是魔法式全局输入.
3. 声子和自由能比单点能量 MAE 更深入地检查势能面.
4. 预训练可以节省数据, 但不能自动消除参考 DFT 的系统偏差.
5. 每个 MatterSim 结果都应注明具体 backbone, checkpoint 和验证范围.
